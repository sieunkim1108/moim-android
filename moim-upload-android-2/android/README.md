# moim 안드로이드 앱

## 여는 방법
1. Android Studio → **File > Open** → `moim-android` 폴더 선택
2. Gradle Sync가 끝나면 ▶ Run (에뮬레이터: Pixel 10)

## 진행 단계
- 1단계 ✅ 프로젝트 세팅: Gradle, Compose, Hilt, Navigation, 디자인 시스템(`ui/theme`), 시작 화면
- 2단계 ✅ 로그인·회원가입 화면 (지금은 목업 저장소, 서버 연결 전)
  - 로그인 / 회원가입 1단계(기본 정보) / 2단계(일정 성향) / 가입 완료
  - 테스트 계정: 학번 `1234567` / 비밀번호 `moim1234`
  - 새로 가입한 계정은 앱을 끄면 사라짐 (목업이라서)
- 3단계 ✅ 메인 눈송이 챗봇 화면 (가짜 눈송이, AI 서버 연결 전)
  - 말로 일정 말하기 → 눈송이 공감 → 확인 카드 → [등록하기]를 눌러야 저장
  - 날짜·시간은 코드(`KoreanDateParser`)가 계산 (오늘/내일/다음 주 월요일/11월 9일/오후 3시 반 ...)
  - 등록 후 일정 성향에 맞춰 공부 알림 제안 (실제 알림은 나중 단계)
  - 해볼 문장: `다음 주 월요일 10시에 데이터 분석 시험이야ㅠㅠ 과제도 금요일까지고`
- 4단계 ✅ 내 캘린더 (메인 상단 왼쪽 달력 아이콘, Stitch: moim_캘린더_첫페이지)
  - [< 2026년 11월 >]로 달 이동, 날짜 아래 점 = 일정 유형 색, 아래 범례
  - 프로필 줄: 나 / 친구(가짜 시은·지원) → 친구 캘린더 보기. 친구의 비공개 일정은 "OOO님의 일정입니다" + 시간만
  - 날짜를 누르면 그날 일정 카드 (알림 시점·공개 범위·장소), [수정]을 누르면 삭제 버튼
  - + 버튼 → 새 일정 등록 (이름, 유형, 날짜·시간, 장소, 알림 1/3/7일 전, 공개 범위)
  - 챗봇에서 등록한 일정도 같은 저장소라 캘린더에 바로 보임
- 5단계 ✅ 채팅방 목록 → 단체 채팅방 → 모임 일정 잡기 (메인 상단 말풍선 아이콘)
  - 채팅방 목록: 전체 / 단체 / 1:1 필터, 안 읽은 수, 진행 중인 투표 표시. 'AI 눈송이' 방을 누르면 메인 채팅으로
  - 단체 채팅방(SW 모바일 팀플방): "언제 만나?"처럼 모임 얘기를 하면 눈송이가 추천 시간 카드를 띄움
  - 모임 일정 잡기: 날짜별 가능 인원 달력, 멤버별 하루 타임라인(비공개 일정은 🔒만), AI 추천 3개
  - 점수는 코드(`MeetupScheduler`)가 계산하고, 눈송이는 이유 설명만 함
  - [이 시간으로 모임 만들기] → 내 캘린더에 '모임' 일정 저장 + 채팅방에 눈송이 안내 메시지

- 6단계 ✅ 최종 보고서(제안서 수정3) 반영 (아직 목업 저장소)
  - 회원가입 1단계: **학교 이메일 인증** (숙명 웹메일 → [인증요청] → 인증번호 6자리 + 3분 타이머 → [확인])
    - 목업 인증번호: 어떤 메일이든 `123456`
  - **자동 로그인**: 로그인 화면의 [자동 로그인]이 켜져 있으면 다음 실행 때 시작 화면을 건너뛰고 메인으로 (DataStore)
    - 목업이라 앱을 끄면 새로 가입한 계정은 사라지고, 테스트 계정(1234567)만 자동 로그인돼요
  - **공개 범위 4종**: 전체 / 친구 / 그룹공개 / 비공개. 새 일정 등록에서 그룹공개를 고르면 단체 채팅방을 골라요
  - **S-12 친구 추가**: 캘린더 프로필 줄 [친구 추가] 또는 채팅 목록 상단 사람+ 아이콘
    - 학번 `2314582`(김민서) 검색 → [친구 요청] / 받은 요청 2건 [수락]하면 캘린더 프로필 줄에 바로 추가
  - **S-11 프로필 수정**: 상단 프로필 아이콘. 이름·학부·전공·성향·알림 시점·기본 공개 범위 저장, 로그아웃
  - 모임 일정 잡기: **희망 소요시간 슬라이더** (30분~4시간+). 바꾸면 달력 색과 추천이 다시 계산돼요

- 7단계 🚧 Supabase 연결 (로그인·학교 메일 인증·내 일정·친구)
  - `local.properties`에 아래 두 줄을 넣으면 Supabase로, 없으면 지금처럼 목업으로 동작해요
    ```
    supabase.url=https://<프로젝트 ref>.supabase.co
    supabase.anonKey=<anon public key>
    ```
  - 넣는 건 **anon key만**. service_role 키는 앱에 절대 넣지 않아요 (Edge Function 환경변수에만)
  - 로그인은 Supabase Auth에 `학번@moim.app`으로 가입/로그인 (비밀번호는 Supabase가 관리)
  - DB 스키마·Edge Function은 `../supabase` 폴더 README 참고
  - 채팅방·DM·모임도 Supabase에 연결됨 (아래 9단계)
- 8단계 🚧 눈송이 ↔ AI 서버 연결 (`../ai-server`)
  - `local.properties`에 `ai.serverUrl=http://10.0.2.2:8000` (에뮬레이터에서 내 컴퓨터의 서버)을 넣으면
    눈송이가 AI 서버(Claude)로 대답해요. Supabase 키도 같이 있어야 해요 (서버가 로그인 토큰으로 사용자 확인)
  - 서버가 꺼져 있거나 실패하면 지금의 규칙 기반 눈송이가 대신 대답해요
  - 일정은 여전히 확인 카드 → [등록하기]를 눌러야 저장
- 9단계 🚧 채팅방·모임을 Supabase Realtime으로 연결
  - 채팅방 목록: `my_rooms()` 함수(마이그레이션 `20261110000001_room_list.sql`)로 마지막 메시지·안 읽은 수·투표 중 표시,
    새 메시지가 오면 실시간으로 다시 불러와요
  - 채팅방: 새 메시지를 Realtime으로 바로 받아요. 방에 들어가면 읽음 처리
  - 모임 확정: `meetups`·`meetup_candidates` 저장 후 `confirm_meetup()`이 멤버 모두의 캘린더에 모임 일정을 넣어요
  - 추천 이유 문장은 AI 서버 `/meetup/explain` (실패하면 기기 안 문장). 점수는 여전히 코드가 계산
  - Supabase 키가 없으면 지금처럼 목업 채팅방으로 동작
- 10단계 ✅ 일정 알림 (WorkManager, 서버 없이 기기 안에서 예약)
  - 시험·과제·약속은 프로필의 알림 시점(1/3/7일 전, 약속은 당일/1/3일 전)에 맞춰 그날 **오전 9시**에 알려요
    - 일정마다 알림을 따로 고르면 그것만 써요. 당일 알림은 시작 1시간 전 (하루 종일·마감 일정은 당일 오전 9시)
    - 수업·기타 일정은 따로 고르지 않으면 알리지 않아요
  - 눈송이가 "11/17(화)부터 공부 알림 보내줄까?" 물을 때 [좋아!] → 그날부터 시험 전날까지 매일 오전 9시,
    [하루 전만] → 전날 오전 9시에만 알려요
  - 일정을 추가·삭제하거나 프로필 알림 시점을 바꾸면 예약이 자동으로 다시 맞춰져요 (`ReminderSyncer`)
  - Android 13 이상은 메인 화면에 처음 들어올 때 알림 권한을 물어봐요
  - 서버 푸시(FCM)는 쓰지 않아서 `google-services.json`이 필요 없어요
  - 확인 방법: 프로필에서 약속 알림을 '당일'로 두고, 1시간 10분 뒤 약속을 등록하면 약 10분 뒤 알림이 와요

## 폴더 구조 (기능 단위)
```
com.moim.app
├─ core/model          여러 기능이 같이 쓰는 모델 (성향, 공개 범위, 일정)
├─ core/data           일정 저장소 (지금은 메모리, 나중에 Supabase)
├─ ui/theme            색, 글꼴, 모서리, 간격 (여기서만 정의)
├─ ui/component        공통 컴포넌트 (버튼, 입력칸, 상단바, 말풍선 ...)
├─ navigation          화면 주소(MoimRoute)와 이동 지도(MoimNavHost)
└─ feature/auth
   ├─ domain           모델, 입력 검사 규칙, Repository 인터페이스, UseCase
   ├─ data             FakeAuthRepository (다음 단계에서 Supabase로 교체)
   ├─ di               Hilt 모듈 (어떤 구현을 쓸지 연결)
   └─ ui               화면(Screen) + ViewModel
├─ feature/calendar    내 캘린더 (domain: 달력·학기 주차 계산 / ui: 달력, 일정 카드, 일정 등록 시트)
├─ feature/dm          채팅방 목록·단체 채팅방 (지금은 가짜 대화방 6개)
├─ feature/meetup      모임 일정 잡기 (domain: 빈 시간 계산·추천 / ui: 가능 인원 달력, 타임라인)
├─ feature/chat        메인 눈송이 챗봇 (domain: 날짜 해석·일정 뽑기 / data: 가짜 눈송이 / ui: 채팅 화면)
├─ feature/friend      친구 추가 S-12 (학번 검색, 친구 요청, 받은 요청 수락/거절)
└─ feature/profile     프로필 수정 S-11 (성향·알림·공개 범위, 로그아웃)
```
